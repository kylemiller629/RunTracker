# User Stories

## MVP User Stories

### User Authentication

#### Sign Up *

As a new user, I want to create an account so that I can save and manage my running activity.

#### Sign In *

As a registered user, I want to sign in so that I can access my saved runs and running information.


### Run Management

#### Add Run *

As a registered user, I want to add a run so that I can keep track of my running activity.

#### View Runs *

As a registered user, I want to view my previous runs so that I can see my running history.

#### View Run Details *

As a registered user, I want to view the details of a run so that I can see the date, distance, time, and pace of that run.

#### Edit Run *

As a registered user, I want to edit a run so that I can correct or update information I entered.

#### Delete Run *

As a registered user, I want to delete a run so that I can remove an incorrect or unwanted entry.


### Running Statistics

#### View Run Pace *

As a registered user, I want the application to calculate my pace for a run so that I can easily see how fast I ran.

#### View Running Summary *

As a registered user, I want to view a summary of my running activity so that I can see information such as my total runs and total distance.

## Non-MVP User Stories

### Running Goals

#### Create Running Goal

As a registered user, I want to create a running goal so that I can work toward a specific mileage or distance target.

#### View Goal Progress

As a registered user, I want to view my progress toward a running goal so that I can see how close I am to completing it.


### Running Statistics

#### View Personal Records

As a registered user, I want to view my personal records so that I can see my best running performances.

#### Filter Run History

As a registered user, I want to filter my running history so that I can find runs from a specific date or distance.


### Weather

#### View Weather for a Run

As a registered user, I want to view weather information for a run so that I can see the conditions in which I ran.


### General

#### About

As a user, I want to learn more about the application and its purpose.
